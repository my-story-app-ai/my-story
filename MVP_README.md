# My Story MVP v0.1

This is a fully client-side clickable demo.

Flow:
1. Add 1–5 people
2. One required + one optional photo per person
3. Choose story type
4. Add story details + up to 5 memory photos
5. Auto-generate preview outline
6. Change inputs or regenerate automatically
7. Generate final sample story

No data leaves the browser in this version.
No manual/human intervention is part of the product flow.
